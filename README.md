# Digital Humanitarian Network — Brand

Brand guidance and official downloadable assets for the Digital Humanitarian Network (DHN), published with GitHub Pages.

## Approval required

These assets may only be used with the **explicit approval of the Digital Humanitarian Network**.
To request permission, email **contact@digitalhumanitarians.com**.

## Contents

- `index.html` — the brand site (logo, colours, typography, backgrounds, usage rules, downloads)
- `` — logo files (PNG, JPG, EPS, AI, PDF, TIF), colour variants, faceted backgrounds, favicon, style guide PDF, and ZIP packs

## Notes

- The style guide names BetaSans Bold (headings) and Clan OT (text). The font files are not included here; the site uses a system sans-serif stand-in.
- The site is static HTML/CSS with no build step. GitHub Pages serves it from the repository root.
